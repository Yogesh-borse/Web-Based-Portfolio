# Web-Based Portfolio

Welcome to my personal web-based portfolio! This portfolio showcases my projects, skills, and contact information, designed to give visitors a clear overview of my work and abilities.

---

## 🚀 Live Demo
Check out the live portfolio here: [Yogesh Portfolio](https://yogesh-portfolio.netlify.app)

---

## 📝 Project Overview
This project is a **personal portfolio website** that includes:  
- A **Home page** with an introduction about me.  
- A **Projects section** showcasing my work.  
- A **Skills section** listing my technical skills.  
- A **Contact section** with email and GitHub information.

---

## 📂 Features
- Clean and responsive design using HTML, CSS, and JavaScript.  
- Easy navigation between sections.  
- Fully hosted online using **Netlify**.  

---

## 💻 Technologies Used
- **HTML5** – Structure and content  
- **CSS3** – Styling and layout  
- **JavaScript** – Interactivity  
- **Git & GitHub** – Version control and repository hosting  
- **Netlify** – Hosting and live deployment
